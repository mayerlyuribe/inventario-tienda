# inventario-tienda
## problema e impacto territorial
En **Támara (Casanare)**, muchas tiendas de barrio llevan el control de sus productos de forma manual o por intuición, lo que genera dos problemas frecuentes: quedarse sin existencias de artículos de alta rotación o acumular productos innecesarios. Esto afecta tanto los ingresos del tendero como el abastecimiento de la comunidad, que depende de estos negocios para sus compras cotidianas, más aún en un municipio donde reponer mercancía implica desplazamientos y tiempos de espera considerables.

Para atender esta situación, proponemos un *programa de control de inventario básico*. El usuario registra cada producto junto con su cantidad en stock, y el sistema evalúa automáticamente si el producto se encuentra en un nivel estable o si requiere reposición. Una vez ingresadas las cantidades de todos los productos, el programa presenta un resumen general con el nombre de cada producto, su stock y el total de productos que deben reponerse. Así, el tendero puede planificar sus compras a tiempo y tomar decisiones con información clara.
